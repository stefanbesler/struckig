SmoothVelocityBrake 

METHOD SmoothVelocityBrake (
 [input] v0 : LREAL,
 [input] a0 : LREAL,
 [input] vTarget : LREAL,
 [input] aMax : LREAL,
 [input] jMax : LREAL)

Jerk-limited brake from (v0, a0) to (vTarget, a=0). Produces a 2- or 3-phase profile that ends with zero acceleration, so Step1 does not inherit a large residual deceleration. jMax > 0 means braking from above (v0 > vTarget), jMax < 0 means from below. If the profile cannot be computed (e.g. a0 opposes braking too strongly), t[0] remains 0 so the caller can fall back to legacy VelocityBrake.

Inputs

v0 LREAL
a0 LREAL
vTarget LREAL
aMax LREAL
jMax LREAL
